WHAT'S CLICKABLE
Tab bar → Home, History, Progress, Library
Start workout (hero card) or + → start today's session
Tap a set's circle → marks it done, starts the 90 s rest timer (Skip to end it)
Finish workout → saves and returns home
Body weight / volume / PR cards → Progress · heatmap → History
DESIGN NOTES
Home now uses your pick — the volt hero — with today's session front and center and a single obvious action. Logging is one tap per set — weights and reps are prefilled from your carry-over loads, so a session is ~14 taps total. "Max" stays "Max" for stack machines. Volt green is the only accent; everything else is monochrome so the accent always means "action or progress".
